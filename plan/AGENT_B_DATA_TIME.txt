B3. server/db.py (all functions in COLLAB 7.2, exact names and signatures)
  - psycopg 3 + psycopg_pool.ConnectionPool (min 1, max 10), opened at import
    or lazily from DATABASE_URL, with search_path set via options or on
    connect. Use dict_row so rows come back as dicts.
  - transaction(): a context manager yielding a pooled conn inside
    conn.transaction(). All functions accept conn=None.
  - Convert timestamps to ISO 8601 UTC 'Z' strings in a helper (iso(dt)), and
    use it in all API-facing dicts.
  - current_price / equity follow COLLAB 5 exactly.
  - price_history: time_bucket_gapfill(bucket, time, since, now()) over
    trades, with locf(last(price,time)) for close. For 5m/1h you may use the
    candles caggs (show both in DEVLOG: cagg for speed, gapfill for
    continuity). Also fall back to price_ticks when a market has no trades
    yet (so charts aren't empty: use ticks' mid, then ai_prior).
  - price_at(market_id, t): last trade price <= t, else last tick mid <= t,
    else ai_prior if the market existed at t, else None.
  - timemachine(t): one query returning, for every race with created_at <=
    t: id, election, position, seats, status as of t ('resolved' if
    resolved_at <= t, 'closed' if closes_at <= t, else 'open'), and every
    candidate market's price as of t (candidates created after t excluded).
    Use a LATERAL join with ORDER BY time DESC LIMIT 1, or last(). Then
    group into the COLLAB 9 timemachine shape in Python.
  - race_history(race_id, bucket, since): one gap-filled query over all the
    race's markets (GROUP BY market_id, time_bucket_gapfill, locf). Returns
    one series per candidate, which powers the multi-line race chart.
  - update_race(id, status=...) applies status (and closes_at) to all the
    race's markets in the same transaction.
  - Race ordering helper: President, Librarian, Treasurer, Secretary, then
    other positions alphabetically.
  - leaderboard: equity for every non-bot user, ranked.
    equity_history: time_bucket over portfolio_snapshots with last(equity).
  - ensure_bot_user: creates "house" (is_bot, cash 100000000, unusable
    password hash) if missing. Returns the id.
  - Write tests (server/tests/test_db*.py) against the real DB with a
    clearly named test prefix for usernames ("test_") and cleanup of only
    rows those tests created. Never truncate.
